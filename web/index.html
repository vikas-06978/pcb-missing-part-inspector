      PCB Inspector

      Missing-component detection by golden-board comparison. Classical computer vision, no training data, and no network access at runtime.

      How it decides

      1. Aligns your photo onto the reference (feature matching, then intensity alignment).
      2. Equalises exposure and focus so only real differences remain.
      3. Measures six independent signals inside each named box.
      4. Fuses them into one confidence, then applies presence vetoes.
